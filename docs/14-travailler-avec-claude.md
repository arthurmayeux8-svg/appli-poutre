# Continuer le projet avec Claude

- **Le projet « Poutre d'escalade »** dans Claude garde une mémoire des décisions importantes. Chaque nouvelle demande ouvre un fil de travail.
- **Ce dossier `docs/`** est la mémoire officielle du projet : il est dans le dépôt GitHub, donc partagé avec toute l'équipe et sauvegardé avec l'historique.
- **Le dépôt GitHub** `arthurmayeux8-svg/appli-poutre` est relié au projet : Claude peut y proposer des modifications sous forme de pull requests.

## Bonnes pratiques

1. Une demande = un message clair (« ajoute… », « corrige… », « explique… »).
2. Relire la pull request, puis cliquer sur **Merge** si c'est bon.
3. Après un merge, le site se met à jour tout seul en quelques minutes.
4. Quand une décision est prise, demander de l'ajouter à `docs/02-decisions.md`.
