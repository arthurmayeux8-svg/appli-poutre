# Le site web

Adresse : **https://arthurmayeux8-svg.github.io/appli-poutre/**

Le site est republié automatiquement à chaque modification de la branche `main` (fichier `.github/workflows/site.yml`).

## Se connecter à la planche depuis le navigateur

| Appareil | Navigateur | Bluetooth |
|---|---|---|
| Android | Chrome | Oui |
| Ordinateur | Chrome ou Edge | Oui |
| iPhone | **Bluefy** (gratuit sur l'App Store) | Oui |
| iPhone | Safari | Non : Apple bloque le Bluetooth (le simulateur marche) |

Dans le site : Paramètres → « Chercher la planche ». Le navigateur affiche la liste : choisir la planche.

## L'ajouter à l'écran d'accueil

- Android / Chrome : menu ⋮ → « Ajouter à l'écran d'accueil ».
- iPhone / Safari : bouton Partager → « Sur l'écran d'accueil » (sans Bluetooth, à cause d'Apple).
- iPhone / Bluefy : ouvrir le site dans Bluefy et l'ajouter en favori.

## Données

Le profil et l'historique sont gardés **dans le navigateur** de l'appareil. Un autre navigateur ou un autre téléphone repart de zéro.

## Première mise en ligne (une seule fois)

Sur GitHub : dépôt → Settings → Pages → Source : « GitHub Actions ». Ensuite, tout est automatique.
