# Glossaire

| Mot | Signification |
|---|---|
| Cellule de charge | Pièce de métal qui se déforme très légèrement sous un poids ; ses jauges transforment cette déformation en un petit signal électrique |
| HX711 | Petit circuit qui amplifie le signal de la cellule et le transforme en nombre pour l'Arduino |
| Tare / remise à zéro | Dire « maintenant, c'est 0 » quand la planche est vide |
| Étalonnage | Régler le facteur qui transforme la mesure en vrais grammes, avec un poids connu |
| BLE | Bluetooth basse consommation, le seul Bluetooth accepté par l'iPhone |
| HM-10 | Module Bluetooth BLE à brancher sur un Arduino UNO |
| Service / caractéristique (FFE0 / FFE1) | « Adresses » Bluetooth par lesquelles passent les messages |
| Protocole | Le format des messages entre la planche et l'appli |
| Web Bluetooth | Le Bluetooth utilisé par un site web (Chrome, Bluefy) |
| Bluefy | Navigateur gratuit pour iPhone qui permet le Bluetooth sur un site |
| React Native / Expo | Outils pour écrire une seule appli pour Android, iPhone et le web |
| Expo Go | Appli de test d'Expo (sans Bluetooth) |
| GitHub | Site qui garde le code et son historique |
| Dépôt | Le dossier du projet sur GitHub |
| Branche | Une copie de travail du code, pour tester des changements sans toucher à la version principale |
| Pull request | Une proposition de modifications, à relire puis à « fusionner » (Merge) |
| GitHub Pages | Hébergement gratuit de site web par GitHub |
| Dissymétrie | Écart de force entre main gauche et main droite, en % |
| Réglette | Prise plate ; sa profondeur se donne en mm |
| Demi-arqué / tendu | Façons de placer les doigts sur la prise |
